# aep_amp_test
AEP offers a program called "AMP (Average Monthly Payments)" which charges you an average of your past 12 months of electricity usage rather than what you actually used that month. I wanted to see if it saves or loses you money over time. This program uses randomness to simulate different usage at different months.

# Conclusion
Whether it saves or causes you to overspend is pretty much a wash based on what the RNG spits out. Ultimately, it seems to be about the same as just paying your monthly bill, but with less volatility in payments. 

# What to do
1. Run the program ( either on your own python terminal, or here: https://www.online-python.com/ ). 
2. Input the number of months you want to simulate.
3. Scroll through the results.
